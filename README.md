# C++ School Projects

A collection of basic C++ programs and coding exercises created during Informatics classes at school. This repository serves as a personal archive of programming practice, examples, and school assignments.

## About This Repository

This repository contains C++ source files covering basic programming concepts, including functions, procedures, parameters, mathematical calculations, conditional logic, and arrays.

Each program was created as part of my learning journey in programming and Informatics class.

## Project Files
